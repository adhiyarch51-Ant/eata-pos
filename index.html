Cara Hubungkan Google Sheet (Apps Script):

  1. Buka Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Paste kode script pemicu webhook: function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var d = JSON.parse(e.postData.contents); sheet.appendRow([d.id, d.date, d.method, d.total, d.items]); return ContentService.createTextOutput("OK"); }
  4. Terapkan (*Deploy*) sebagai **Web App** (akses disetel ke: *Anyone/Siapa Saja*).
  5. Salin URL Web App yang dihasilkan dan tempelkan pada kolom Google Spreadsheet Webhook di atas.
